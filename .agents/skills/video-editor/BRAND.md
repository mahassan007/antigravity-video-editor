# Brand sheet

Starter preset for Techy Souls talking-head clips. These values can be edited before a job.

| Element | Default |
| --- | --- |
| Canvas | 1080 × 1920 vertical. Fit footage inside the canvas and pad where required to preserve framing. |
| Caption font | Bold sans serif, Inter if installed, otherwise Arial or an available equivalent. |
| Caption text | White with a dark outline. Up to two lines, broken at natural phrases. |
| Accent | Emerald (#34D399) for selected keywords or callouts, where readable. |
| Placement | Lower middle, with generous bottom clearance and room at right for platform controls. Move captions if they cover the face or important screen content. |
| Motion | Static captions by default. A brief title or callout can animate if the edit calls for it. |
| Audio | Original speech with consistent loudness. |
